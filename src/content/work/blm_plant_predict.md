The goal of the project was to see if we could use aerial imagery to map vegetation in Gunnison sage-grouse habitat to help sage-grouse management. Some of the questions we had were:

## Test Header

- What percent sagebrush cover do sage-grouse prefer in any given season?
- What percent bare ground is avoided if any?
- How far do grouse avoid PJ?

We classified 4 band (red, blue, green, and near infrared), 10 cm resolution. There was also a point cloud that was used to orthorectify the imagery that was at fine enough of a scale that we used it to try and get height of some vegetation. I don't think we put a lot of thought into what bands we wanted for classification because the imagery was purchased in a rush with end of the year money.
